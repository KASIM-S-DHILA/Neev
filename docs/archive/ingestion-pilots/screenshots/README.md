# Screenshots (archived)

UI evidence from the Phases 1–7 ingestion work, captured at the time each
report was written. Historical only — the current UI is not expected to match
these.

See the [parent README](../README.md) for the index and for what superseded
each phase.

Live smoke screenshots are **not** stored here. `smoke:desktop` writes to
`tmp/smoke-screenshots/`, which is ignored, so running the gate does not dirty
the working tree.

- `phase-01-workspace*.{png,jpg}` — workspace shell, browser and desktop
- `phase-02-*`, `phase-03-*` — Materials and extraction views
- `phase-04-*` — OCR and text rendering in the browser
- `phase-05-*` — selective cloud vision, slides, workspace
- `phase-05-workspace-desktop.png` — the historical desktop smoke screenshot
- `phase-06-audio-desktop.png` — audio transcript review
- `phase-07a-video-desktop.png` — video playback and transcript
- `phase-07b-frames-desktop.png` — selected frame grid
- `phase-07c-*-desktop.png` — frame text review
- `youtube-desktop.png`, `youtube-media-desktop.png` — caption review and attached local media
- `automatic-groq-desktop.png`, `cloud-*-desktop.png`, `cloud-extracted-text-*.png` — cloud routing notices
